# Flappython 🐱

A Flappy Bird-style game developed using Python and Pygame.

## 🎮 Features

- 🐱 Player-controlled character with jump mechanics
- 🧱 Moving obstacles with randomly generated heights
- 💥 Collision detection
- 🏆 Score system
- ☁️ Scrolling background and ground
- 🔊 Sound effects for jumping, collisions and scoring
- 🎯 60 FPS gameplay
- 🧩 Object-oriented programming using `Player` and `Pipe` classes

## 🛠️ Technologies

- Python
- Pygame

## 🚀 Running the Game

### Requirements

- Python 3
- Pygame

### Installation

Install Pygame using:

```bash
python3 -m pip install pygame
```

### Start the Game

Make sure you are inside the flappy cat folder:

```bash
cd "flappy cat"
```

### Then run:

```bash
python3 flappybird.py
```

### Important: The game must be run from the flappy cat folder because it loads its images, sounds and font using relative file paths.

### 🎮 Controls
Space — Jump
